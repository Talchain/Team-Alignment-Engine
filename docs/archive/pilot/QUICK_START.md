# TAE Phase D - Quick Start Guide

**Get started in 15 minutes!**

---

## 1. Log In (2 minutes)

**URL:** `https://tae-staging.olumi.com`

**Credentials:** Check your email for invite link

**First time?** Complete profile setup (name, role, goals)

---

## 2. Create a Decision (3 minutes)

1. Click **"+ New Decision"**
2. Fill in:
   - Topic: What are you deciding?
   - Type: Feature, pricing, hiring, etc.
   - Context: Why this matters
   - Stakeholders: Add your team
3. Click **"Create"**

---

## 3. Add Your Perspective (2 minutes)

1. Go to **"Perspectives"** tab
2. Click **"Add My Perspective"**
3. Enter:
   - Goals (what you want - rank them!)
   - Concerns (what worries you)
   - Constraints (any limitations)
4. Save

---

## 4. Propose Options (3 minutes)

1. **"Options"** tab → **"+ Propose"**
2. Describe each option:
   - Name: "Option A"
   - Description: What this means
   - Assumptions: What needs to be true
   - Trade-offs: What you're giving up

**Tip:** Try **"AI Suggest"** for AI-generated options!

---

## 5. Vote (2 minutes)

1. **"Voting"** tab
2. Rate each option:
   - 🟢 Strong Support
   - 🟡 Mild Support
   - ⚪ Neutral
   - 🟠 Mild Concern
   - 🔴 Strong Concern

3. TAE calculates fit scores and alignment

---

## 6. Reach Alignment (2 minutes)

1. Click **"Move to Alignment"**
2. Review TAE's recommendation
3. Discuss any disagreements
4. Click **"Finalize Decision"** when ready

---

## 7. Document Outcome (1 minute)

Record:
- What you decided
- Why you chose it
- Next actions

**Done!** ✅

## Phase D Features to Try

Once comfortable with basics, explore:

- Dashboard → Analytics
- Track trends over time

### 🌐 Cross-Team Coordination (D6)
- Dashboard → Coordination
- Detect cross-team conflicts
- Coordinate dependencies

## Common Workflows

### Daily Check-In (2 minutes)
```
1. Log in
2. Check "My Decisions" - any actions needed?
3. Review notifications
4. Update in-progress decisions
```

### Weekly Team Review (15 minutes)
```
1. Navigate to Portfolio
2. Review team's health score
3. Identify bottlenecks
4. Check for dependency conflicts
5. Read AI strategic insights
```

### Decision Creation (30-60 minutes)
```
1. Create decision
2. Add all stakeholders
3. Collect perspectives
4. Generate/propose options
5. Async voting over 1-2 days
6. Sync alignment meeting
7. Finalize and document
```

## Tips for Success

✅ Add all relevant stakeholders upfront

✅ Be specific in perspectives (not "it should be fast" → "delivery within 2 weeks")

✅ Propose 3-5 options (not just 2)

✅ Explain your votes

✅ Complete retrospectives (feeds organizational learning!)

✅ Use dependencies to link related decisions

✅ Check portfolio weekly
